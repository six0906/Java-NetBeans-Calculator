# Java-NetBeans-Calculator
*My first major individual Java project as a sophomore.*
A basic calculator built with Java Swing in NetBeans. This was my first major individual Java project as a sophomore.

## Features
- Addition, subtraction, multiplication, and division
- Number buttons (0-9) and a decimal point
- Clear and delete buttons
- Simple graphical interface built with the NetBeans GUI Builder

## How to Run
1. Download or clone this repository.
2. Open NetBeans and go to **File → Open Project**, then select the project folder.
3. Press **F6** (or click **Run Project**) to start the calculator.

## Built With
- Java
- Swing
- NetBeans IDE
